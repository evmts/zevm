Connect Agent & One-Time Sandbox Auth

Agents interact with ZEVM issues, PRs, flows, docs, and artifacts through the authenticated Smithers Cloud MCP server. Never embed long-lived credentials in prompts or container images.

1. Streamable HTTP MCP Endpoint 
{
  "mcpServers": {
    "zevm-smithers-cloud": {
      "type": "streamable-http",
      "url": "https://smithers.sh/evmts/zevm/mcp"
    }
  }
}
2. Print One-Time-Use Sandbox Attach Auth 
scripts/sandbox-auth --mode attach
# Prints one-time BYOA pairing code (RFC 7636 PKCE, 8h scoped smat_ token)
3. Untrusted External Contributor Run (Read-Only Cache) 
scripts/sandbox-auth --mode untrusted --pr 42
# Runs tests and Lighthouse audit in isolated pr-42 read-only cache namespace

Trust boundary: approvals and merges are locked to authenticated maintainers (person). External contributor runs are encouraged and never write to trunk cache on build.smithers.sh.
