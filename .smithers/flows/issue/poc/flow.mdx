repository root with `jj --no-pager`. Do not push, merge, move `main`, post
GitHub comments, close issues, or publish npm packages.

   the code under test (`src/*_test.zig`), using `std.testing.allocator`.
2. Implement the smallest fix. Follow the Zig style rules in `CLAUDE.md`: no
   private imported-symbol aliases and explicit allocator ownership.

   test, push it, and bump `native-dependencies.json` to the pushed revision.
4. Keep new Zig files inside the root `PACKAGE.ts` source closure and update
   the owning `bench/<suite>/PACKAGE.ts` when a bench suite imports them.

`smthrs ci '//...'`. For C ABI or N-API changes also confirm `//:c-smoke` and
`//:npm-smoke`. Any failed or unavailable check blocks a production-ready claim.
